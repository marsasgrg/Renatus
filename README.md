# Important Information
CK3 Mod Recreation of the world of [Renatus Nation RP](https://discord.gg/nUXrrT89), currently focused on the human areas of the southern continent.
Map based on the [Blank Map](https://steamcommunity.com/sharedfiles/filedetails/?id=3632276914).

# Installation Guide
This will soon be on Steam, however before that you can only download this from Github.
1. Click Code -> Download Zip
1. Find your CK3 LOCAL [not cloud] saves folder; let's call it Crusader Kings III/saves
1. Now, go to Crusader Kings III/mod
1. Unzip the zip file into mod/Renatus [as in, the files have to be directly in mod/Renatus, not mod/Renatus/Renatus]
1. Copy descriptor.mod into the Crusader Kings III/mod/ folder
1. At the end of the copied descriptor.mod, add `path = "(your CK3 folder)/mod/Renatus"`
1. The mod should now be accessible through the Paradox Launcher
1. Create a playset with the mod, and use it to launch the game
